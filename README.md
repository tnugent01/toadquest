# Toad Quest: The Sacred Scrolls

A 2D vertical swamp platformer created for the Google Deepmind x Cerebral Valley Hackathon Tokyo 2026!

> **⚠️ CAUTION: API KEY REQUIRED**  
> To play this game and talk to the NPCs, or to generate new assets, you must plug your own Gemini API key into the code.  
> 
> Please set your API key in the following files:
> - `game.js` (line 205): `const GEMINI_API_KEY = "YOUR_API_KEY_HERE";`
> - `generate_assets.py` (line 6): `API_KEY = "YOUR_API_KEY_HERE"`
> - `generate_jump_anim.py` (line 11): `API_KEY = "YOUR_API_KEY_HERE"`

## Tools Used
- Gemini 3.1 Pro
- Claude Opus 4.6
- Cursor Composer 1.5
